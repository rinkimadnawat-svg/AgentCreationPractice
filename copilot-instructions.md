# Repository instructions

- This repository is a demonstration using fictional BrightBite Foods data only.
- Never introduce real personal, customer, employee, company, credential, or confidential data.
- Use Python 3.11+, small pure functions, type hints, and concise docstrings.
- Keep ingestion, validation, analytics, recommendation, export, and UI logic separate.
- Do not silently impute, delete, publish, deploy, commit, or push.
- Preserve raw input; report rejected or corrected records explicitly.
- Add or update pytest tests for material logic changes.
- Before editing, state the files and acceptance criteria affected.
- Before running installation, deletion, publishing, or Git commands, request human approval.
- Treat AI output as a draft requiring human verification.
