# Create management Excel

1. Read `references/workbook-standard.md`.
2. Create sheets: Executive Summary, Priority Issues, Action Tracker, Data Quality, Methodology.
3. Freeze headers, apply filters, readable widths, date/number formats and restrained styling.
4. Include visible filter scope and generation timestamp.
5. Use formulas for editable action tracking fields where appropriate.
6. Put methodology and limitations in the workbook.
7. Verify every export sheet has content and opens successfully.
