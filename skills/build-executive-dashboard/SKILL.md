# Build executive dashboard

1. Read `references/dashboard-standard.md`.
2. Start from decisions and users, not available charts.
3. Put headline KPIs and the most urgent decision above the fold.
4. Use sidebar filters consistently and show active filter scope.
5. Use accessible labels, restrained colour and human-readable error states.
6. Keep calculations outside Streamlit pages.
7. Cache only deterministic data-loading or transformation functions.
8. Test empty upload, invalid schema, no-result filters and export.
