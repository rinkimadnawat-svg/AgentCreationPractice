# Translate analysis to actions

For each action, produce:
- signal
- supporting evidence
- business implication
- recommended intervention
- suggested owner role
- urgency
- verification metric
- caveat

Separate observation from interpretation. Do not claim causality. Use the configured priority score only as a triage aid. Prefer actions that are specific, reversible and measurable.
